# Reproducibility

## What is included

This repository contains:
- the original project notebook;
- a modular Python organization of the available project code;
- configuration and dependency files;
- documentation and selected result figures.

## What is not included

The SVD recordings are not redistributed in this repository.

The published paper describes a multimodal SVD workflow using speech and EGG recordings. The notebook and modular scripts available here contain a generalized/local-data pipeline and should therefore be treated as the implementation available in this repository, not as a guarantee of exact reproduction of every published experiment.

## Reproducing the published numbers

The paper-reported values should only be quoted as reported results. Exact reproduction requires the authorized dataset, the original experimental setup, preprocessing choices, labels, software versions, random seeds, and hardware/environment used for the experiment.

## Data handling

Never commit restricted or non-redistributable recordings to GitHub. Keep the dataset locally and follow its access/licensing conditions.
