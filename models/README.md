# Models

Trained model weights are intentionally not stored in this repository.

The model-building code is available under `src/model.py` and the ensemble implementation is under `src/ensemble.py`.

If you later publish trained weights, document:
- the exact dataset split;
- preprocessing/scaler artifacts;
- label mapping;
- software versions;
- training seed;
- model version;
- license/redistribution terms.
